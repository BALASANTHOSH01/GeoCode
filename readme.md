# Geocode

`Geocode` is a lightweight JavaScript/TypeScript library for working with country data, phone numbers, flags, and geolocation.  
It provides easy-to-use methods to search countries, validate and format phone numbers, load flags, detect user country, and access country emojis.

---

## Features

- Search countries by **name** or **ISO code**
- Lookup countries by **phone code**
- Format and validate **phone numbers** per country
- Parse **full international phone numbers**
- Load **flags** as URLs or SVG content
- Detect **user country** via IP
- Get **country emojis**
- Utility helpers for cleaning numbers, validating ISO codes, and normalizing country names
